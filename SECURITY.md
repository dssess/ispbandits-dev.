# Security policy

This is a proprietary alpha intended for private development. Do not place production credentials, customer databases, private keys, or backups in the repository. The installer is local-source-only and currently installs only the management foundation; it does not configure VPN listeners.

Before any production deployment, complete SSH account isolation, Xray configuration validation, service rollback, privilege review, and clean-image tests. Report vulnerabilities privately to the ISPbandits Dev project owner; do not include live VPS passwords, private keys, or customer connection details in an issue.
